# DIMPLE-GWAS Freeze 3 interpretation

Mode: `native`. Original-space similarity: `pearson`.

This directory is a post-run diagnostic package. It does not refit UMAP or HDBSCAN, change labels, or alter model ranking. `heatmap_order.tsv`, `cluster_cutpoints.tsv`, `cluster_summary.tsv`, and `projection_quality.tsv` are the machine-readable sources for the visual report.

The figure renders 24 of 24 vectors using `none` sampling. The complete similarity table is retained when enabled. Coordinate associations, if present, are descriptive correlations and are not loadings, drivers, mechanisms, or causal effects.
